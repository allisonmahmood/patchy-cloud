---
title: Patchy Cloud
description: Where a company's own tools live.
---

Patchy Cloud runs the tools a company builds for itself. Each one is a patch, anything from a single page to a full CRM, at one address in the company's cloud. A person, or an agent acting for them, publishes it through the `patchy` CLI; colleagues open it in their browser.

- [Patches and tiers](/docs/patches-and-tiers): what a patch is, and where its code runs.
- [Tables](/docs/tables): defining a patch's own tables and reading and writing their rows.
- [Limits](/docs/limits): the contract and operating limits the cloud enforces.
