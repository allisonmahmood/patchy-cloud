For the design decision

B · Publish first

A new team can be created in the publishing context, and its people remain visible alongside the audience. This saves a context switch but adds a team editor to the publish workspace.

Create team → Choose audience → Publish → Find / open → Remove → Refuse → Restore

Contract and limits

This is a static storyboard for #1234, using #1192 as the contract. No actual access control is implemented or demonstrated. The local build is #1235, after Srikar picks a direction.

First publish requires Company or one named team. A supplied audience satisfies the choice; a missing one does not publish. Only an owner who can open the patch may publish again. Removing Alex from Design would deny both open and publish; re-adding Alex is recovery. Team membership grants no publishing rights to Maya.

No new roles, multiple-team selection, ownership handoff, connections, data resources, migrations or production changes. MCP, runtime handlers, live subscriptions, shared resources and guest/public access are outside this preview.
